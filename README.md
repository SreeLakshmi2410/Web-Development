## Project-1: Profile Landing Page (HTML, CSS)

A simple, responsive profile/landing page built with HTML and CSS.

- Profile picture, short bio, and social links
- Clean, minimal styling using CSS

Files:
- project-1/

  - styles.css — stylesheet for the landing page

How to view:
1. Clone the repo: `git clone https://github.com/SreeLakshmi2410/Web-Development.git`
2. Open `project-1/index.html` in your browser.
